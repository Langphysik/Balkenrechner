Formelsammlung▸

Kurzübersicht der wichtigsten Zusammenhänge – ersetzt nicht das Skript, hilft aber als Spickzettel bei den Aufgaben.

Gleichgewicht am ebenen Balken

ΣFx = 0  ·  ΣFy = 0  ·  ΣM(beliebiger Punkt) = 0

Drei Gleichungen → drei unbekannte Auflagerreaktionen bestimmbar (statisch bestimmtes System).

Auflagerreaktionen

Festlager: 2 Unbekannte (waagrecht + senkrecht)  ·  Loslager: 1 Unbekannte (senkrecht zur Gleitrichtung)

Anzahl Unbekannte r = 3 → statisch bestimmt · r > 3 → statisch unbestimmt.

Streckenlast → Resultierende

R = q · l

Angriffspunkt in der Mitte der Streckenlast (bei konstantem q).

Hebelgesetz

ΣMA = 0:   F · a = B · l  →  B = F·a / l  ·  A = F − B

a = Abstand der Kraft von A, l = Auflagerabstand.

Kraftzerlegung am geneigten Balken

F∥ = F · cos φ    F⊥ = F · sin φ

φ = Winkel zwischen Kraft und Balkenachse; F∥ wirkt in Richtung der Normalkraft, F⊥ in Richtung der Querkraft.

Schnittgrößen N, Q, M

N: Normalkraft (Zug/Druck)  ·  Q: Querkraft  ·  M: Biegemoment

dQ/dx = −q(x)  ·  dM/dx = Q(x) → M ist extremal, wo Q = 0 ist.

Statische Bestimmtheit

f = r − 3   (r = Anzahl Auflagerreaktionen, eben, ohne Gelenke)

f = 0: statisch bestimmt · f > 0: f-fach statisch unbestimmt · f < 0: kinematisch verschieblich.
